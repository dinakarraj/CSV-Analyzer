# 🤖 AI CSV Analyser

An AI-powered CSV data analysis tool that allows users to upload a CSV file and ask questions about their data using natural language.

The project combines **Google Gemini** for natural-language query understanding with **Pandas** for reliable data processing and analysis. A **Streamlit** interface provides a simple interactive UI.

---

## 🚀 Features

- 📂 Upload CSV files through a Streamlit interface
- 💬 Ask questions about the uploaded dataset using natural language
- 🤖 Use Google Gemini to convert natural-language questions into structured JSON
- 🔎 Filter data using natural-language conditions
- 📊 Perform aggregations such as:
  - Sum
  - Average
  - Median
  - Highest
  - Lowest
  - Count
- 🗂️ Group data by one or more columns
- ↕️ Sort results in ascending or descending order
- 🔢 Limit the number of returned rows
- 🔠 Case-insensitive text filtering
- ⚙️ Support comparison operators:
  - `=`
  - `!=`
  - `>`
  - `<`
  - `>=`
  - `<=`
- 🧹 Defensive handling of Gemini JSON responses
- 📋 Display the structured query generated by Gemini
- 📈 Display the final Pandas result directly in the UI
